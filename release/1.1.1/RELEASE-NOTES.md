## 1.1.0 之后的改动

代码补全改为输入时自动弹出：

- 输入两个字母，或输入 `.`、`->`、`::`、`#`、`#include <` 后自动弹出候选；注释、字符串、数字里不弹；
- 列表随输入实时收窄，Enter 或 Tab 接受，Esc 关闭；
- 导入运行库后合并 clangd 的语义候选，显示函数签名和返回类型，接受时只插入名字；
- 平板上点选候选不会让软键盘收起；候选项加高便于手指点选；
- 设置 → 编辑 或 编辑菜单里可以关闭；关闭后 Ctrl+Space 或 编辑 → 代码补全仍可手动触发；
- 编辑器右上角的「补全」按钮移除。

修复：

- 手动补全接受 clangd 候选时会把整个函数签名（如 `printf(const char *restrict format, ...)`）插进代码；
- `->` 后面的成员不提示；
- 没有候选时，运行中按 Esc 有时停不下程序。

## 安装

直接覆盖安装 `DogeIDEPlus-1.1.1-debug.apk`，项目草稿与设置保留。运行库已导入的无需重新导入。

此 APK 使用 debug 签名，包名为 `com.doge.ide.plus.debug`，用于测试分发，不是商店正式签名包。
