## 1.0.1 之后的改动

编辑与输入：

- 修复 Tab 后连续输入被吞字：编辑器强制使用隐藏 textarea 输入，规避 Android 输入法与 contenteditable 的组合输入冲突；
- 平板新增可点的「补全」入口（编辑菜单 / Ctrl+Space），无物理键盘也能触发补全；
- 无文件时编辑器只读并提示「请先新建文件或者选择要编辑的文件」；
- 运行库就绪后由 clangd 诊断接管，关闭本地对 C/C++ 的「未定义名」误报下划线。

运行与输出：

- 运行中按钮可点击并显示「停止」，不再需要键盘取消；
- 任务路径全部加请求超时（8s）、连续失败熔断（5 次）、总时长上限与停止兜底（10s），本地服务无响应时不再永久卡死；
- 运行输出加 512K 上限并改为增量渲染，长输出不再撑爆内存、贴底才自动滚动；
- 直连执行与任务队列串行化，取消只作用于目标任务，不再误杀其他任务。

稳定性（Java / native）：

- 项目保存串行化，避免并发写坏 SAF 目录；
- 依赖管理改单例并原子写 registry.json；
- 构建缓存清理不再误删整份缓存；
- 修复 native 管道在错误路径下的文件描述符泄漏；
- 编译输出读取线程改为守护线程并在超时后主动关流；
- 每次启动清理残留的临时编译目录。

界面与体验：

- 顶栏与提示条在窄屏下自适应换行，提示条移到底部居中不再遮挡运行按钮；
- 各弹窗统一支持 Esc / 点遮罩关闭、Enter 提交、焦点不逃出；
- 导入进度 90 秒无更新可「后台继续」，不再永久卡遮罩；
- 覆盖安装即可更新（修复此前 WebView 缓存导致需卸载重装的问题）；
- 按钮补充无障碍标签。

## 安装和首次运行

1. 安装 `DogeIDEPlus-1.0.2-debug.apk`（可直接覆盖 1.0.1，无需卸载）。
2. 打开 Doge IDE+，点击「导入运行库」。
3. 选择 `doge-cpp-arm64-0.1.0.zip`。
4. 点击项目面板的 Open，选择一个项目目录。
5. 编辑文件后点击 Save 写回项目目录。

此 APK 使用 debug 签名，包名为 `com.doge.ide.plus.debug`，用于测试分发，不是商店正式签名包。
