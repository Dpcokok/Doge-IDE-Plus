## 1.1.1 之后的改动

修复：

- 补全列表打开时按 Tab 变成了缩进，没有接受候选。现在 Tab 在编辑器处理按键之前就先接受候选；输入法还在组字时按 Tab，会等字母上屏后再接受；输入法把 Tab 当成文字送进来时也能接受。没有候选列表时 Tab 照常缩进。

识别项目里自己写的头文件：

- `#include "` 后自动列出项目里的头文件，按当前文件所在目录、项目根目录、设置里的 include 路径来写相对路径，接受时自动补上收尾引号；
- 当前文件 `#include "…"` 进来的头文件（包括头文件里再 include 的）中声明的函数、宏、类型、枚举常量、结构体成员会出现在补全候选里，排在最前，并显示函数签名和所在文件。不需要导入运行库，改完头文件立即生效；
- 头文件里声明过的名字不再被标成“未定义”的波浪线；
- 导入运行库后，clangd 也按同样的规则查找项目头文件，并带上设置里的 include 路径和宏定义；
- 编译时 `#include "…"` 除了源文件所在目录，也会在项目根目录查找（子目录里的源文件可以直接 include 根目录的头文件）。只作用于双引号形式，不影响 `#include <…>` 的标准库头文件。

## 安装

此 APK 使用 debug 签名，包名为 `com.doge.ide.plus.debug`，用于测试分发，不是商店正式签名包。
