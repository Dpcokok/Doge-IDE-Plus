# Doge IDE+ 1.1.0 测试发布版

发布日期：2026-09-29

1.1 系列的第一个版本，启用全新的工作台界面：菜单栏、活动栏、资源管理器、多标签编辑器、底部面板（问题 / 输出 / 任务）和状态栏。原界面的字体与配色保留为「经典」主题，可在设置里切换。

## 1.0.2 之后的改动

界面：

- 新工作台布局：菜单栏（文件 / 编辑 / 运行 / 视图 / 帮助）+ 活动栏 + 资源管理器 + 编辑区 + 底部面板 + 状态栏；资源管理器宽度、面板高度可拖动并记住；
- 默认使用「现代」主题；原 1.0.x 配色作为「经典」主题保留（设置 → 外观），1.0.x 升级上来且选过经典的用户保持不变；
- 命令面板（Ctrl+Shift+P）可搜到全部命令；快捷键表由命令表自动生成；新增「关于」（点状态栏版本号）；
- 设置改为居中对话框，分外观 / 运行 / 构建 / 键盘四组。

编辑：

- 多标签：每个文件独立撤销历史，标签与文件树显示未保存点，Ctrl+W 关闭；
- 文件树按目录分组、可折叠，支持右键 / 长按菜单；新增重命名文件（F2），断点、标签随之更新；
- 编辑器内查找 / 替换（Ctrl+F / Ctrl+H，编辑菜单也可点）；
- 项目内搜索（活动栏第 2 格 / Ctrl+Shift+F）：区分大小写、全字、正则，点击结果跳到对应位置。

运行与输出：

- 底部面板分为问题 / 输出 / 任务三个视图；输出内分 stdin / stdout / stderr / info，每个流单独记住滚动位置；
- 「问题」视图汇总编译错误、警告与 clangd 诊断，按文件分组，点击跳到对应行；编译出错时自动打开；状态栏显示错误 / 警告数；
- 任务视图显示每次运行的状态与耗时；
- Ctrl+L 一次清空全部输出（修复 1.1 开发期间「清空」按钮报错的问题）。

键盘与触控：

- 快捷键统一路由：对话框打开时只响应 Esc；编辑器内的撤销、补全、Tab 不会被抢；Esc 逐层关闭弹窗，无弹窗且运行中时停止执行；
- 设置里可关闭 Ctrl+I（部分输入法用它切换中英文）；
- 触控设备上可点区域统一不小于 44px；
- 分屏 / 竖屏（宽度 ≤ 920px）时资源管理器改为覆盖层，点空白处、选中文件或按 Esc 收起；运行按钮始终可见；
- 软键盘弹出时收起底部面板与状态栏，给编辑器让出空间；在 stdin 里输入时改为收起编辑区。

## 安装和首次运行

1. 安装 `DogeIDEPlus-1.1.0-debug.apk`（可直接覆盖 1.0.x，无需卸载；项目草稿与设置保留）。
2. 打开 Doge IDE+，点击菜单栏右侧的「运行库未导入」，或 帮助 → 导入本地运行库。
3. 选择 `doge-cpp-arm64-0.1.0.zip`。
4. 文件 → 打开项目，选择一个项目目录；或 文件 → 新建项目。
5. 编辑后 Ctrl+S（或 文件 → 保存项目到目录）写回项目目录。

## 已知情况

- 这一版的 1.1 新界面**尚未在平板真机上完整验证**：构建、单元测试（415 项）与桌面浏览器模拟（触控、多视口、软键盘，149 项）全部通过，但开发期间平板未连接调试。外接键盘逐键、中文输入法下的 Ctrl+Space / Ctrl+I、真实软键盘高度需要在设备上确认。
- 调试（断点单步）入口仍隐藏，与 1.0.x 相同。

此 APK 使用 debug 签名，包名为 `com.doge.ide.plus.debug`，用于测试分发，不是商店正式签名包。
