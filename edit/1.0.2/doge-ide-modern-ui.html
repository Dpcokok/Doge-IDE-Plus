DOGE IDE+ · 界面参考原型

散落的按钮，收进一条菜单栏。

旧版把能力压在顶栏一排小图标和项目面板头部的「＋ － ‹」上；新版用标准六菜单（文件 / 编辑 / 运行 / 视图 / 调试 / 帮助）加命令面板承接，功能不减，顶栏与面板头的 11 个散点收敛到 2 处。上方可直接操作：打开文件菜单、右键文件、拖动分隔线、按 Ctrl+Shift+P。

改了什么

三个结构性决定，而不是换皮。

入口上收到菜单栏

新建文件从项目面板头部的「+」移到 File 菜单，同时保留 Ctrl+N 与面板头图标三条路径，键盘、鼠标、触屏都能到。

命令面板兜住长尾

Ctrl+Shift+P 汇总全部 38 条命令，支持模糊匹配。任何原来只能靠记忆快捷键才能触发的操作都能被搜到。

输出区拆成两级

旧的 stdout / stderr / info / Tasks / debug 五个平级标签，升级为「问题 · 输出 · 调试控制台 · 任务 · 终端」五个面板视图，输出视图内再用分段控件切流。
