# 括号补全、可选连字和全角符号提示

日期：2026-10-07（Asia/Shanghai）

## 使用

设置 → 编辑增加三个选项，保存后立即生效并在下次启动保留：

| 设置 | 默认 | 行为 |
|---|---|---|
| 自动补齐括号 | 开启 | 输入 `(`、`[`、`{` 补齐右侧；选中文本可包裹，空括号成对退格删除 |
| 启用符号合并 | 关闭 | 使用现有 Maple Mono 字体连字，只改变编辑器字形 |
| 检查全角符号 | 开启 | 代码中错误的全角标点、中文引号等标红，并列入问题视图 |

软键盘通过直接提交文本进入 CodeMirror 时，之前不会触发按键式括号补全。这次补齐该
路径，也处理组字结束提交、已有右括号跳过、选区包裹和撤销；粘贴整段文本不额外补括号。
引号采用 CodeMirror 的现有语言规则；`<`、`>` 不自动配对，以免影响比较运算符。

符号合并完全由 OpenType 字体显示控制。当前打包字体支持 `>=`、`<=`、`->`、`----`
等连字，已用截图对照验证实际字形变化。编辑器原来的默认样式允许 contextual 连字，
因此关闭时明确禁用 `calt/liga`，开启时显式恢复。源码、光标字符索引、查找、草稿保存、
复制文本、执行请求仍保持原 ASCII。设置仅作用于源码编辑器，不替换为 Unicode 字符，
不改变终端或输出面板。

全角检查使用 CodeMirror 的字符串/注释 token 排除正常中文文本；C/C++ 预处理行的
字符串另做处理，避免 `#define MSG "中文，合法"` 误报。普通数据文件不作为代码检查。
支持常见全角 ASCII 标点、中文括号/引号、全角空格及误用的乘除符号；不会自动替换。
全角字母和数字不属于本规则的标点错误。该检查无需运行库，clangd 就绪后继续执行。
“问题”视图显示行列和半角建议，点击跳转；同行多个相同符号分别计数，修正后红线消失。
当前诊断作用于正在编辑的文件，最多显示 500 处，尚未实现全部未打开文件的批量扫描。
